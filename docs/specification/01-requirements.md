# App 需求

免费、简体中文、遥控器操作的 Android 直播客户端。保留已有直播、恢复、收藏、节目单和支持频道回看功能。程序不自带私人频道，不承担搜集与线路审查。使用者自行配置有权访问的 HTTPS JSON 目录。

公开首次启动为空目录，提示通过菜单设置。私用构建允许显式本地配置；安装包不是公开发行品。旧用户沿用包名/签名覆盖安装，收藏 ID、有效目录缓存保留。运行中的目录更新不打断正在观看的频道，失败回退旧目录。APK 更新来自公开 App 仓库，与频道目录独立。

新仓库不迁移旧 Git 历史；源代码基线为 2026-11-03 已有实现，首次拆分版本为 0.5.0-alpha / 20。不操作家庭设备。
