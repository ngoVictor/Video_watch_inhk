# App 架构

app -> core；core 只含平台无关频道模型、播放策略和接口。app/catalog 解析、校验、缓存和刷新目录；app/playback 适配 Media3；app/guide 负责节目单/回看；app/update 独立校验和安装 APK；UI 协调遥控器交互。频道发现、质量审查和生成器属于外部生产者，不进入本仓库。

公开构建内置空目录。显式 -PprivateCatalogDir=<本地目录> 生成私用 assets，目录中 channels.json、catalog-config.json 与 private-update-token.txt 仅进入本地 APK。普通 Release 不自动读取隐藏配置。公开发布工具拒绝包含非空内置目录、配置或 token 的 APK。

目录使用 GitHub contents 时，凭据绑定到配置时的精确 HTTPS 地址；更换地址需重新绑定凭据。HTTP 重定向不携带认证。APK 更新始终不携带目录凭据。Keystore 加密保存设备凭据；不能将加密存储或 APK 内置文件视为不可提取的保密设施。私用 APK 仅交给频道授权使用者。

JDK 17、Gradle 8.11.1、AGP 8.9.2、SDK 35，Media3 1.7.1、Jellyfin FFmpeg 音频扩展 1.6.1+2；视频解码与播放阈值不因拆分改变。

## 本地工作区

本仓库作为工作区容器内独立的 Video_watch_inhk 文件夹存在，拥有自己的 .git、规范、工具和状态文件。所有工作命令以本仓库为根；不依赖目录生产者的源码位置。本机 local.properties 和被忽略的构建辅助文件可指向已安装 SDK/JDK，不提交机器绝对路径。

## 基线审查补充

公开源码包与公开 APK 使用同一内置目录检查：channels 必须为空数组；强制加入 Git 的 .private 或私有配置文件同样拒绝打包。源码检查先于输出，失败不得改变旧源码包。

## 现行运行行为（对照代码复核）

目录启动先加载内置快照与有效缓存，取较高 revision；远程目录完整校验后原子替换，失败保留旧表。仅应用运行期间每六小时检查目录、每天检查软件；维护页可立即检查。有效目录更新不会打断正在观看的频道，下次重新播放才使用新的频道对象。

core/FailoverPolicy 使用单调时间：启动缓冲达到12秒、播放进度停滞8秒触发恢复；已开始后持续缓冲画质模式8秒/流畅模式6秒，或60秒内三次再缓冲，先降低画质并观察15秒，再失败换线。健康连续30秒建立频道线路偏好，120秒恢复正常画质并清除该线路失败扣分。失败冷却15/30/60/120秒，断网等待恢复。健康分数留在当前控制器，偏好通过 sourceId 与 URL 摘要匹配持久化、24小时失效；不持久化单调时钟冷却。

Media3 负责同一媒体内的自适应，core 负责跨 URL 换线。正常上限1080p，画质/流畅预算12/8 Mbps；恢复目标720p、预算6/4 Mbps，高清源不静默选低于720p的分支。不同步启动多个解码器。仅音频解码可用固定 FFmpeg 扩展，视频保持 Media3 平台解码。

收藏保留稳定频道 ID，即使频道暂时离开目录也不删除收藏。节目单按香港日期窗口过滤；仅有精确映射的频道支持节目单；非空同日缓存20分钟内复用，失败或空响应可回退同日缓存，最多64项。回看与直播独立切换播放器，后台/维护返回可恢复进程内回看位置；不承诺跨进程回看续播。

APK 更新独立使用公共清单；校验大小、SHA-256、包名、递增版本、设备兼容性和安装签名，私有频道凭据不参与。以上是实现行为，不是家庭设备长期观看验收。
