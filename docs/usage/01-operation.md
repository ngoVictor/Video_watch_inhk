# 电视操作

公开版首次启动没有频道：按菜单键或设置键进入维护页，设置 HTTPS 目录地址；私有 GitHub 目录需另设读取凭据。家庭版已配置目录时可直接使用。


以下操作以当前 0.5.0 客户端实现为准。更新失败会显示原因和错误码。

## 使用方法

- 直播时按左键或确定打开选台面板，重新打开会定位当前频道；左侧仅分类、频道与“我的收藏”。在分类列上下移焦时，右侧立即显示对应频道，无需确认；移焦不会换台，确认频道才播放。左右键切换两列，返回收起。
- 全屏时按右键打开当前频道操作；频道列表中可长按确定打开所选频道操作，提供收藏与节目单入口。菜单键或设置键打开维护页，切换“画质优先 / 流畅优先”及更新设置。
- 维护页点击“检查频道与软件更新”，下载验证完成后选择“安装已下载的新版本”，按系统提示确认。
- 全屏时上键切列表上一台、下键切下一台；独立 CH+/CH- 保持下一台/上一台。菜单内上下键仍按对应方向移焦。换台在当前播放分类内首尾循环，跳过无线路频道。仅预览其他分类不会改变换台范围。可加入/取消收藏、收藏并置顶；从“我的收藏”确认播放后，在可播放收藏中按收藏顺序循环；从普通分类确认频道后，恢复该分类内循环。收藏与播放范围在本机保存，更新 APK 或重启不清除。
- “查看节目单 / 回看”进入全屏大字号界面，左侧日期、右侧当天节目。可浏览前七天至后天；今天/明天/后天同时标明月日和星期，均按香港时间。日期上下移焦后加载，不抢走日期栏焦点；右键进入节目，节目列左键回日期、右键进入时段，时段向下回节目。
- 时段可选全天、凌晨（00–06）、上午（06–12）、下午（12–18）、晚间（18–24）。跨时段节目会出现在相关时段内，时间列显式标记跨日的“前一天”“次日”。打开今天自动定位正在播出的节目，切换日期恢复全天；“回到今天”一键复位。只加载所选日期，不预取全部日期或频道。
- 预告标注“未播出”，确认只提示尚未播出；已播节目的查询回看、官方网页重温、暂无回看分别显示。空日期提示尚未提供数据，不代表当天停播；空时段可切回全天。节目状态会定时刷新，跨午夜仍保留用户正在浏览的实际日期。
- 节目单键可直接打开当前频道的节目单；无此按键仍可从频道操作进入。央视 21 个映射（包括 4K、8K、5+、4 欧洲版）及翡翠台、明珠台、TVB Plus、无线新闻台已接入；其他频道明确提示未接入。网络失败可按“重试”，同日缓存回退会注明，空响应不会覆盖有效缓存。
- 央视加载失败时自动尝试官网和 EPG.pw 备用表，底栏显示实际来源；无需选择节目单线路。备用表仅有节目时间和名称，不会凭空生成回看入口。4K/8K 有节目表仍不代表已接入直播线路。
- 选择正在播出的节目进入对应直播；选择带“查询回看”的已播节目时，再向官方确认资源。没有资源会提示，不能保证节目单中所有节目都能回看。
- TVB 标有“官方重温页面”的已播节目会先说明，然后另开 myTV SUPER 官方节目页面；可看集数及免费范围由官方决定。此入口不是本应用内视频回放，没有可打开网页的应用时会提示。
- 回看中确定暂停/继续，左右快退/快进 30 秒，返回键回到原直播频道。播放结束停留提示，不自动重新播放；进入后台释放解码器，返回时恢复位置及暂停状态。进程被系统回收后仍以原直播频道启动，不承诺跨进程保存回看进度。

## 审查修复行为

首次加载期间进入后台或维护页，返回后继续记住的频道。目录更新后重新播放使用同一频道的新线路；频道已移除时明确提示。下载更新时返回电视会先取消下载并清理临时文件，然后恢复原直播或回看模式；不会因为取消更新而丢失回看位置及暂停状态。
